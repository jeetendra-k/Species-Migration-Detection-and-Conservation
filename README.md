# 🌍 Wildlife Migration Analysis & Habitat Suitability Prediction

## Overview

An AI-powered web application for analyzing wildlife occurrence data,
predicting habitat suitability, forecasting population trends, and
visualizing migration patterns using real biodiversity and environmental
datasets.

Built using **Python**, **Streamlit**, **Machine Learning**, **Google
Earth Engine**, and **GBIF**.

## Features

-   Interactive wildlife distribution map
-   Population prediction using Machine Learning
-   Habitat suitability assessment
-   Migration simulation
-   Species occurrence clustering
-   Environmental analysis (Temperature, Rainfall, NDVI)
-   AI-generated ecological explanations
-   Multi-species support

## Technologies

-   Python
-   Streamlit
-   Pandas
-   NumPy
-   Scikit-learn
-   Matplotlib
-   PyDeck

-   GBIF
-   OpenAI API

## Workflow

1.  Collect GBIF occurrence records.
2.  Clean and preprocess datasets.
3.  Integrate environmental variables.
4.  Cluster occurrence locations.
5.  Train ML models.
6.  Simulate migration.
7.  Visualize results in Streamlit.

## Installation

``` bash
git clone https://github.com/yourusername/species-migration.git
cd species-migration
pip install -r requirements.txt
streamlit run app.py
```
